# smart-calendar-pro

AI-powered calendar management for OpenClaw agents. Natural language scheduling, conflict detection, and smart reminders.

## Features

- 📅 Natural language event creation ("lunch with Anna on Thursday")
- ⚡ Conflict detection with automatic suggestions
- 🔔 Smart reminders based on travel time and event importance
- 🌍 Multi-timezone support
- 🔄 Sync with Google Calendar, Outlook, Apple Calendar

## Installation

```bash
openclaw skill install smart-calendar-pro
```

## Usage

Once installed, your agent can:

- **Create events:** "Schedule a meeting with the team next Tuesday at 2pm"
- **Check availability:** "Am I free tomorrow afternoon?"
- **Set reminders:** "Remind me about the dentist 1 hour before"
- **Reschedule:** "Move my 3pm to 4pm"

## Configuration

Add to your agent config:

```yaml
skills:
  smart-calendar-pro:
    default_calendar: primary
    reminder_minutes: [10, 30]
    timezone: auto  # uses system timezone
```

## API Reference

### Tools Provided

| Tool | Description |
|------|-------------|
| `calendar_create` | Create a new event |
| `calendar_list` | List upcoming events |
| `calendar_check` | Check availability |
| `calendar_remind` | Set a reminder |
| `calendar_reschedule` | Move an event |

### Examples

```
User: "Book a 30min sync with Erik tomorrow at 10"
Agent: ✅ Created "Sync with Erik" — Tomorrow 10:00-10:30 CET
```
